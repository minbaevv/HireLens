# HireLens — Фичи по фидбэку Динары + аудит

Дата: 2026-07-23. Ветка изменений поверх миграции `v1u5t0s49q3r`.

## 1. Что реализовано (запросы пилотного клиента Динары)

### 1.1 Телефон / WhatsApp кандидата (HIGH)
Раньше форма отклика собирала только email, и HR вручную выцарапывал номер из резюме.

- **БД:** новая колонка `candidates.phone` (`String(32)`, nullable). Миграция `w2v6u1t50r4s_add_candidate_phone.py`.
- **Форма отклика** (`ApplyPage.jsx`): новое необязательное поле «Телефон / WhatsApp» с подсказкой.
- **API** (`/api/apply/{token}`): принимает `phone` (Form), санитизирует и сохраняет.
- **Карточка кандидата** (`CandidateDetailPage.jsx`): телефон выводится ссылкой `https://wa.me/<цифры>` — HR открывает WhatsApp в один клик (закрывает просьбу «давать фидбек через WhatsApp»).
- **Список кандидатов** (`CandidatesPage.jsx`): телефон под email.
- **Экспорт** (`export.py`): колонка «Телефон» в CSV/Excel + строка в PDF. Индексы числовых колонок Excel (Оценка/Пре-скрин) скорректированы после вставки колонки.
- **Схемы:** `CandidateOut`, `CandidateListItem`, `CandidateApply` расширены полем `phone`.

### 1.2 Обязательные (предварительные) вопросы рекрутёра (HIGH)
Рекрутёр хочет, чтобы AI гарантированно задавал свои вопросы (например для линейного персонала: возраст, город, учится ли).

- **БД:** новая колонка `jobs.mandatory_questions` (`Text`, JSON-массив строк, nullable). Миграция `x3w7v2u61s5t_add_job_mandatory_questions.py`.
- **Форма вакансии** (`JobsPage.jsx`): блок «Обязательные вопросы» — добавление/редактирование/удаление, пустые отсекаются.
- **API** (`jobs.py`): `_clean_questions()` — trim, отсечение пустых, лимит 20 вопросов × 500 символов; сериализация в JSON при создании/обновлении.
- **AI-интервью** (`interview_service.py`): `_mandatory_questions_block()` добавляет вопросы в системный промпт **после** форматинга шаблона — работает и с кастомными шаблонами компаний. AI обязан задать каждый вопрос в дополнение к адаптивным.
- **Схемы:** `JobCreate`/`JobUpdate`/`JobOut` расширены; `JobOut` парсит JSON→list. `JobPublicOut` намеренно НЕ отдаёт вопросы (кандидат их заранее не видит).

### 1.3 i18n
Все новые строки добавлены на ru / ky / en (поле телефона, блок обязательных вопросов).

## 3. Замечания аудита (НЕ исправлял — на решение владельца)

- **Скидка пилота 20% vs 30%:** в переписке озвучено 20%, а по цифрам (4900→3430, 12900→9030) получается ровно 30%. Нужно зафиксировать одно значение (задокументировано в GROWTH_PLAN v50).
- **`datetime.utcnow()`** — 16 наивных вызовов (deprecation в Python 3.13). Рекомендуется `datetime.now(timezone.utc)`.
- **CI `.gitlab-ci.yml`:** два джоба с `allow_failure: true` (маскируют падения линта/тестов) + нет `--cov-fail-under`. Убрать после стабилизации.
- **Мусор в репозитории:** `ngrok.exe` (32 МБ), `test.db` (284 КБ ×2) — добавить в `.gitignore` и удалить из репо.
- **CORS/URL по умолчанию** в `config.py` указывают на localhost — ок, т.к. переопределяются через env в проде; проверить, что env заданы.
